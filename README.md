# ThermographyProject

A Thermography Converter egy Android alkalmazás, amely hőmérséklet-átváltást és alapvető hőtan definíciókat kínál felhasználóbarát módon.
A projekt célja, hogy a felhasználók gyorsan és egyszerűen átválthassanak Celsius, Kelvin és Fahrenheit hőmérsékleti skálák között, valamint megismerhessék a hőtan és az egyes hőmérsékleti egységek definícióját.
